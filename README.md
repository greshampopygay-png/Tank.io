# TANCHIKI.io — Render starter

Это готовая минимальная multiplayer-игра: один Node.js Web Service, WebSocket, ПК + телефон.

## Локальный запуск

1. Установи Node.js 20+.
2. В этой папке выполни:
   npm install
   npm start
3. Открой:
   http://localhost:10000

## Render

1. Создай GitHub repository и загрузи содержимое этой папки.
2. На Render: New → Web Service → выбери GitHub repository.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Deploy.

Сервер сам использует `process.env.PORT` и слушает `0.0.0.0`, поэтому подходит для Render.

## Управление

ПК:
- WASD — движение
- мышь — прицел
- ЛКМ — стрельба

Телефон:
- левый джойстик — движение
- правый джойстик — направление + автоматическая стрельба
